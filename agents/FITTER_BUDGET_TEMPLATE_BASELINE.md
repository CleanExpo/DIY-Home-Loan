# FITTER budget template — baseline (from MoneySmart upward)

Foundation for DIY (internal, no member redirect):

- Local seed workbook: `C:\Users\dunca\Downloads\budget-planner_moneysmart.xls`
- Fitzy Budget Builder in `index.html` is the member-facing tool.

Fitzy uses the same structural ideas (income/expense grouping, frequency awareness, custom items), but keeps members on the DIY website and layers DIY-specific rows so every member file is comparable quarter to quarter.

## What we inherit from MoneySmart thinking

- Income and expenses in one place, with correct frequency (skewed totals if frequency is wrong).
- Payslip deductions (super, salary sacrifice, etc.) handled honestly: add back to income if needed, then show as expense where appropriate.
- Regular refresh with **actual** bank and card history — the planner is a snapshot; accuracy comes from updating against reality.

## FITTER / DIY extensions (add to the spreadsheet or parallel tab)

Use these so Rule 3, 8, 11, 12, 14, and 15 stay visible in the same document:

| Section | Purpose |
|--------|---------|
| **Household scope** | Explicit: all adults in the household; joint where shared |
| **Cash in / cash out** | Physical cash — easy to miss without a habit |
| **Family loans** | Inflows, repayments, agreed terms (aligns with “no other loans” exceptions) |
| **GISI surplus (planned)** | Monthly amount committed above minimum P&I (Rule 14) |
| **Quarter label** | e.g. 2026 Q2 — file version |
| **vs last quarter** | Short variance notes (what changed, what surprised you) |
| **Irregular / future 12 months** | Holidays, medical, car lump costs, insurance renewals, gifts |
| **LOC discipline note** | Reminder: investment draws stay matched to GISI discipline (no narrative advice) |
